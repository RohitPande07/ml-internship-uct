# Project 5 – Crop and Weed Detection

**Machine Learning Internship – UCT** · Area: Agriculture

## 1. Company
UCT – machine-learning internship programme covering agriculture, predictive maintenance, smart city and industrial manufacturing.

## 2. Background
Weeds compete with crops for nutrients, water and land, reducing yield. Farmers usually spray pesticide over the whole field, wasting chemicals and leaving residues on crops. The dataset contains **1300 images (512×512 RGB)** of sesame crop and weeds, labelled with bounding boxes in **YOLO format**.

## 3. Problem statement and relevance
Detect and localise *crop* vs *weed* in field images so that a sprayer can treat **only weeds**. This reduces pesticide use, cost and crop contamination.

## 4. Design
```
photos (4000×3000) → cleaning (589→546) → resize 512×512 → augmentation (→1300) → manual YOLO labels
      → train/val/test split (70/20/10, grouped to avoid leakage) → YOLOv8 → detections → spray planner → nozzle commands
```
* **Detector:** YOLOv8 (nano by default, `--model yolov8s.pt` for more accuracy), transfer learning from COCO weights.
* **Classes:** `0 = crop`, `1 = weed` (change `CLASS_NAMES` if your label files differ).
* **Spray logic:** `spray_planner.py` discards low-confidence weeds and weeds overlapping a crop box, then opens the nozzle lane containing each remaining weed.

## 5. Implementation
| File | Purpose |
|---|---|
| `src/augment.py` | Resize originals to 512×512 and grow the set to ~1300 images with flips + brightness/contrast jitter; transforms labels consistently |
| `src/prepare_dataset.py` | Splits into train/val/test (augmented copies of one photo stay in the same split) and writes `data.yaml` |
| `src/train.py` | Trains YOLOv8, evaluates on the test split (mAP, precision, recall) |
| `src/predict.py` | Inference on images/folders/video, saves annotated output, prints nozzle plan |
| `src/spray_planner.py` | Detections → selective-spray commands (unit-testable, no model needed) |

Run:
```bash
pip install -r requirements.txt
# dataset already has 1300 labelled images:
python src/prepare_dataset.py --raw data/raw --out data/yolo
python src/train.py --data data/yolo/data.yaml --epochs 100
python src/predict.py --weights outputs/crop_weed/weights/best.pt --source data/yolo/images/test
```
Dataset: Google Drive link in the internship brief (extract to `data/raw/images` and `data/raw/labels`).

## 7. Learnings
* Data quality matters more than model size: removing bad photos (589→546) and consistent labelling drove results.
* Augmented copies of the same photo must stay in one split, otherwise validation scores are inflated.
* Normalised YOLO labels make resizing trivial; flips need the box centre mirrored (`x → 1-x`).
* Limitations: one crop (sesame), one field/season; lighting and growth-stage changes may hurt generalisation. Augmented data is not a substitute for new field images.
* Future work: more crops and conditions, segmentation for overlapping plants, deployment on Jetson/Raspberry Pi with real nozzle hardware.
